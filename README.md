# pots-phone-to-bluetooth
A device which connects to a POTS via phone line to a modern cell phone via bluetooth to act as a call device

## Development Environment Setup

1. Install Visual Studio Code
2. Install the [ESP-IDF extension](https://docs.espressif.com/projects/esp-idf/en/v4.2.3/esp32/get-started/vscode-setup.html) in VS Code
